## Реализация

Создан собственный учебный корпус из восьми документов и набор из восьми контрольных запросов. Символьный TF-IDF индекс собирается до запуска API и включается в образ. Реализованы `/live`, `/ready`, `/search`, `/meta` и режим `reverse`. Helm chart принимает только образ по digest, использует ClusterIP, probes и ограничения привилегий. Подготовлены workflow GitHub Actions и сценарий проверки отката.

Исходный retrieval-сервис и оригинальный оценочный набор преподавателя в переданной папке отсутствовали; использованные корпус и контрольные запросы разработаны отдельно для этой реализации. Их небольшой размер ограничивает выводы о качестве и не заменяет оценку на исходном наборе, если он предусмотрен.
